# LibertyBasics
This is a set of basic Liberty Labs designed to be run in the user laptop. The idea is to provide the experience of installing and testing all components needed to run some basic Liberty demos that are usually provided automatically in other TechZone environments.

Lab instructions provided in https://github.com/sebasporro/LibertyBasics/blob/main/Liberty_Introductory_Labs_Guide.md
